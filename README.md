# 💼 Job-On-Go

A job application platform enabling users to browse listings, apply in real-time, and manage their job search — built with Vue 3 and Firebase.

🔗 **Live Demo:** [job-on-go.vercel.app](https://job-on-go.vercel.app)

## Overview

Job-On-Go was built to give job seekers a fast, real-time platform for discovering and applying to opportunities, backed by Firebase for authentication and live data sync — removing the friction of slow, outdated job application processes.

## Features

- 🔍 Browse and search job listings in real-time
- 🔐 Secure user authentication via Firebase
- 📝 Apply to listings directly within the platform
- 🤖 Conversational assistant integration via Dialogflow
- ⚡ Real-time data sync powered by Firestore
- 🎨 Responsive UI styled with Tailwind CSS

## Tech Stack

- **Framework:** Vue 3 + Vite
- **Language:** TypeScript
- **Backend & Database:** Firebase (Firestore, Cloud Functions)
- **Styling:** Tailwind CSS
- **Conversational AI:** Dialogflow

## Getting Started

### Prerequisites
- Node.js installed
- A Firebase project with Firestore and Authentication enabled

### Installation

```bash
git clone https://github.com/Hillariousice/job-on-go.git
cd job-on-go
npm install
```

### Run the App

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
